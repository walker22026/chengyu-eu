Today I finally subscribed to GitHub Copilot. At $10/month, I think it's worth it — Copilot's code assistance is strong enough to meaningfully speed up how I write code. As a developer, I'm writing code fairly often, and having intelligent suggestions and autocomplete while I type is a real help.

I'm hoping Copilot saves me enough time on the mechanical parts of coding that I can put more of my energy into the more creative, higher-level parts of development. Carving out time to code every day has become a habit of mine, and now that I have Copilot in the mix, I expect that to get even more productive.
